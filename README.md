# Virtual Box Web App

This is a web-based project that lets you load an ISO file to run an operating system directly in your browser.

## Features
* **ISO File Upload:** Select and load operating system ISO files.
* **Virtualization:** Run your chosen OS directly from the web interface.
* **Web & Mobile Friendly:** Designed to be converted into an Android app using PWABuilder.

## How to Use
1. Visit the published website URL.
2. Select your `.iso` file using the file picker.
3. Click start to launch the operating system environment.
